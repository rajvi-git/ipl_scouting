# IPL Scouting Project

This project builds a scouting workflow for identifying Syed Mushtaq Ali Trophy players who may be interesting IPL recruitment targets. The final approach uses simple EDA, role-specific impact scores, K-means player profiles, and nearest-neighbor matching to compare domestic players with similar IPL player types.

`IPL_Scouting_Results_Notebook.ipynb` is the final submission. The key result files are in `reports/scouting/`, including `scouting_shortlist.csv` and the optional static dashboard at `reports/scouting/dashboard.html`. GitHub repository: https://github.com/rajvi-git/ipl_scouting
